`session_load` now returns the child session's current metadata as a `metadata` field next to the transcript page: identity, title, session properties (with the recorded web URL whole or omitted), and observed repositories. The projection is safe (no execution overrides, raw extensions, or worker-resolved defaults), reflects current session state even for a prompt-scoped page restricted to an older turn, and stays a pure read — no activation, resume, repair, or mutation. A missing metadata record reads as `metadata: null`; a broker failure is an error. Stored variable values are opt-in via `include_variables: true` (default false) and returned only as bounded previews: at most eight key-sorted entries, each with a head/tail clip capped at 256 escaped JSON bytes plus exact `total_bytes`/`omitted_bytes`, and a `variables_summary` of total/returned/omitted counts. The whole metadata field is capped at min(4096 bytes, a quarter of the read budget) measured on the compact serialized JSON, degrading to a `{"truncated": true}` marker and then to omission. Optional metadata and optional progress never stall, overflow, or consume a cursor: the same loaded window is refitted with them reduced or dropped, and only a mandatory-only page that cannot deliver usable content returns a recoverable error asking for a larger `read.max_output_bytes`. (issue #2970)
